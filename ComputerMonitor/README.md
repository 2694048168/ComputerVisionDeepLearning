## 工控机系统资源实时监控

> [Wei Li Blog](https://2694048168.github.io/blog/)

> Intelligent Monitoring, 监控系统资源, 包括CPU, GPU, 内存, 磁盘, IO, 网络等, 便于分析和评估工业中针对工控机的选型参考. 

### **Features**
- [x] 工控机系统资源监控
	- CPU 总体利用率, 均衡负载(每一个core利用率)监控, 进程(软件)CPU监控
	- Memory 内存利用率实时监控
	- Disk 磁盘利用率实时监控
- [x] 监控数据导出
	- 支持 CSV, Excel, Text 格式导出监控数据
	- 支持图形绘制后, 以图像方式导出
